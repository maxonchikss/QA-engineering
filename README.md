# QA Engineering 

Welcome to my Quality Assurance portfolio. This repository demonstrates practical skills in various testing methodologies acquired during the "Software Verification and Testing" course at RTU MIREA.

## Objective
Showcase proficiency in the full software testing lifecycle: from requirement analysis and test design to execution, defect reporting, and advanced verification techniques like mutation testing.

## Core Competencies
- **Testing Methodologies:** Black-Box, White-Box, Unit, Integration, Mutation Testing, TDD, BDD, ATDD, SDD
- **Test Design Techniques:** Boundary Value Analysis, Equivalence Partitioning, State Transition
- **Tools & Frameworks:** Python, `pytest`, `MutPy`, `coverage.py`, Git, Android Studio, Pylint, Valgrind
- **Documentation:** Test Plans, Test Cases, Bug Reports (aligned with ISO/IEC/IEEE 29119 and GOST standards)

## Project Structure (Branches)
Each branch represents a completed practical module:

- [`black-box-testing`](../../tree/black-box-testing): End-to-end black-box testing of the HatUp Android MVP, including test case design and defect reporting.
- [`unit-mutation-testing`](../../tree/unit-mutation-testing): Development of Python modules with injected defects, followed by `pytest` unit testing and `MutPy` mutation analysis (achieved 100% mutation score).
- [`test-driven-development`](../../tree/test-driven-development): Implementation of TDD, ATDD, BDD, and SDD methodologies for a File Encryptor utility.
- [`static-dynamic-analysis`](../../tree/static-dynamic-analysis): Static (Pylint, SonarQube) and dynamic (Valgrind) code analysis.
- [`test-planning-tms`](../../tree/test-planning-tms): Test plan creation and practical usage of Test Management Systems.
